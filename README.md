# Sohby — صحبي

نسخة ويب جاهزة للنشر على Vercel مع Neon PostgreSQL.

## المزايا
- إنشاء حساب حقيقي
- تسجيل دخول وخروج حقيقي
- جلسة مستخدم محفوظة في Cookie آمنة
- صفحة رئيسية
- نشر منشورات نصية
- عرض آخر المنشورات
- حذف منشورك
- تصميم عربي RTL ومتجاوب للموبايل

## 1) قاعدة البيانات
في Neon افتح SQL Editor وشغّل الملف:
`schema.sql`

## 2) Vercel
ارفع هذا المشروع إلى GitHub ثم استورده في Vercel.

أضف Environment Variable:
`DATABASE_URL`
واجعل قيمتها هي رابط اتصال Neon.

بعد إضافة المتغير أعد النشر.

## ملاحظة
لا تضع DATABASE_URL داخل ملفات المشروع أو GitHub.
