# Sohby - صحبي

نسخة Vercel جاهزة كتطبيق ويب اجتماعي عربي.

## التشغيل
لا تحتاج PHP ولا build command. ارفع الملفات إلى GitHub ثم استورد المستودع في Vercel.

## ملاحظة
هذه النسخة MVP تعمل مباشرة داخل المتصفح وتخزن الحسابات والمنشورات في LocalStorage.  
لتحويلها إلى منصة حقيقية متعددة المستخدمين نضيف قاعدة بيانات ومصادقة سحابية في المرحلة التالية.

## مهم
لا تستخدم `now-php` أو إعداد PHP لهذا المشروع.
